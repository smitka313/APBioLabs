Serengeti Ripple Effects

Why does protecting the migration matter to organisms that never migrate?

15–20 min
Serengeti Board Game

Build the web

Drag one part of the ecosystem onto another, or tap the two parts in order. With a keyboard, use Tab and Enter or Space to select the start and end of the arrow. Press Esc to cancel.

Start with the herd: where does the dung on this patch come from?

Solid arrow: increases. Dashed arrow: decreases. Arrows show influence, not where food moves.

Review your connections and why they work

    Predict and compare

    Model limit: A value of 100 is the starting point, not a field count. An encounter means predators had a chance to find prey; it does not count predators.

    What happens to dung beetle activity if half as many wildebeest visit this patch?

    Move half the herd

    Drag two wildebeest groups to the neighboring patch, or select each group and then the destination. Use Tab and Enter or Space to do this with a keyboard. Only the study patch is measured.

    Study patch

    Select a group on the study patch first.

    Watch the ripple move across the patch

    Each card reads usual visit → fewer visitors. 100 is the starting index, not a count.

    Explain the ripple

    Direct or indirect? Wildebeest add dung directly. To affect the beetles, they first have to change the dung supply. That’s an indirect effect: it takes more than one arrow.

    Write both responses to finish.

    What this model can and can’t show

    Both runs start with the same index of 100 for each component. Index values show relative change, not field counts or percentages. Only visiting wildebeest changes between runs; each arrow takes one model step, not a fixed number of days. The strengths are illustrative and vary slightly across datasets.

    This is one patch, not the whole migration. It leaves out weather, other grazers, other sources of dung, and feedback from grass to herd size. Standing grass can respond to both grazing and soil inputs. Predator encounters are opportunities to encounter prey, not predator population size.
