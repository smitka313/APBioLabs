Where does my work go?

Your name, class period, answers, and recorded results stay in the browser profile where you work. “Sign in” sets a name and period on that device; it does not create an online account. The site does not upload your lab work or automatically sync it with another device, browser, or school account.

To continue an activity, use the same site address and browser profile. Private browsing, school laptops that reset, and clearing this site’s browser data can leave you without the saved copy. If the site says it cannot save, do not count on a refresh keeping your work. Export whatever you can while it is still visible, and ask your teacher for help before closing the page.

Using a shared device?

  1. Check the name and class period before working. If the saved work is not yours, stop. Changing the displayed name does not create a new profile or make that work yours.
  2. When you finish, save your report and any progress files or backups you need. Confirm they downloaded and close the other Lab Bench tabs.
  3. Use Sign out or Switch student and read the confirmation. This removes the current name and all AP Biology and OpenSciEd work saved in that browser. It does not erase files you already downloaded; follow your school’s instructions for removing personal files from a shared device.

The OpenSciEd dashboard also has Clear saved OpenSciEd work, which leaves your name and AP Biology work in place. Use this only when you intend to clear that course, and back up first.

Turning in work is different from backing it up

  • To turn it in: In AP Biology, open Submit. In OpenSciEd, open Preview report inside the activity. Review the name, period, and work before downloading or printing. Use the format your teacher asks for and submit it through your school’s usual channel. Downloading does not submit it.
  • To move editable AP work: From Submit, use the progress file (.json) or resume code and load it in the same lab on the new device. A printed PDF or Word report is not a substitute for this transfer step.
  • To keep OpenSciEd work: Return to the same browser profile to keep editing. If you must change devices, save a Word or PDF report before switching so you have a copy. A report or a dashboard backup cannot restore editable work. A dashboard backup can include records from more than one student and is not for turning in.

Reports, progress files, backups, and resume codes can contain personal information or saved answers. Keep them private and send only the requested file through your school’s approved channel.

For teachers reviewing AP files

The class dashboard reads supported Word reports and progress files in the current browser tab. It does not upload the files or track a live roster. Closing or reloading the tab clears the list of imports. For a dashboard import, ask for Word or progress files, not PDFs. Treat CSV exports as student work.

Page visits and outside resources

Biology Lab Bench uses GoatCounter to count page visits without analytics cookies. Student names, class periods, reports, and activity answers are not part of those counts.

Some activities show media or resources from other sites, such as embedded videos. Your browser connects to the outside provider to load that resource. The provider may receive ordinary connection information and apply its own privacy settings. If you follow an outside link, that site’s rules apply.

What if a resource is blocked?

  • The lab or save controls will not work: Open the activity directly in a school-approved browser rather than inside an LMS preview. Check that JavaScript and site storage are allowed. Do not clear site data as a first step; that can erase work.
  • A video or outside resource will not open: Use the transcript, evidence cards, or other replacement provided in the activity if there is one. If the missing resource is required, tell your teacher which resource failed so they can provide another option.
  • A Word download fails: Some Word exports need to load a file-building library from an outside site. Try Save as PDF or another export offered by the activity if your teacher accepts it. If the print window is blocked, open the activity in its own tab and ask your teacher or school tech support before changing managed settings.

Teachers: test the assigned activity on a student device and school network before class. Check saving, any required media, the export format you plan to collect, and the school’s submission process.

Still need help?

For assignment or device-access questions, start with your teacher or school support. For a site problem, use Feedback and bug reports and include the activity, browser or device, and the action that did not work. Leave out student names, Dataset IDs, reports, and screenshots showing personal information.
